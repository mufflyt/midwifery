# REBUILD_VERIFY_ONLY mode reads every artifact's .provenance.json and compares
# the recorded input SHA-256 against the current upstream file. It was correct
# and permanently red -- 107 stale at once -- so a NEW stale artifact was
# indistinguishable from the standing 107, and the only place the verdict
# appeared was a console line on whichever machine held the private data. CI
# runs the check and SKIPs by design, because the runner has no freeze.
#
# With this file, a new stale artifact FAILS and these are reported. The full
# per-artifact detail, including which input moved and whether it was data or
# the producing code, is in artifacts/freeze_freshness_report.csv.

#   artifacts/dac_hospital_affiliation_summary.csv

# all (most of this project's inputs are person-level and gitignored), so
# freshness cannot be established either way. check_provenance() reports both as
# stale because a missing file's hash is NA; the report splits them, because
