# Artifacts whose sidecar does not name the code that produced it
# =============================================================================
# A3 proves a sidecar EXISTS. It does not prove the sidecar says anything.
# A sidecar with code_sha256: null records the inputs but not the producer,
# so the artifact cannot be regenerated and a change in the generating code
# leaves no trace. That is most of what a sidecar is for.
#
# The usual cause is write_with_provenance() called from `Rscript -e`:
# .code_closure() resolves the producer from the --file= entry of
# commandArgs(), and an inline call has none. Writing the same code into a
# script file and running that fixes it.
#
# Same rule as every other baseline here: this list MAY SHRINK AND MUST
# NEVER GROW. A new artifact with null code provenance fails A3b.
# Generated 2026-11-10 from the tracked tree.
# =============================================================================
