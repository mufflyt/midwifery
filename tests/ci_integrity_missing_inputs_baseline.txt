# code change, and three of them are worse than they look:
#
#   data/wonder/natality_2016_2024_cnm_by_county.csv
#       THE MANUAL WONDER EXPORT. There is no API path for county natality --
#       WONDER refuses sub-national queries through the web service -- so this
#       can only be regenerated by replaying data/wonder/D66_Defaults.xml
#       through the web UI by hand, under WONDER's data-use agreement. Every
#       CNM-attended-birth figure in the README rests on it.
#   data/county_base.csv
#       The county spine, read by build_cd_midwifery_stats.R,
#       build_cd_provider_counts.R, build_county_midwifery_supply.R and
#       map_midwife_geography.R. Its .provenance.json sidecar was deleted with
#       it, so the SHA-256 of the four inputs that built it is gone as well.
#   data/ct_legacy_to_region_weights.csv, data/ct_tract_crosswalk_2022.csv
#       The Connecticut apportionment onto the nine planning regions. Without
#       them the weights are rebuilt from the Census API, which needs a key.
