# =============================================================================
# ci_nightly_exceptions.txt -- tests the nightly may not execute normally
# =============================================================================
# The nightly DISCOVERS tests by glob. This file is the only way a discovered
# test is treated differently, and it lists ONLY exceptions -- never the normal
# tests. If this file ever grows to resemble a test manifest, the discovery
# contract has been inverted and the nightly has stopped protecting anything.
#
# Format:  <path><TAB or spaces><class>  # reason
#
# class is one of:
#   external-private   needs a private repository this public CI cannot clone.
#                      Runs in the `external-deps` job, reported, NOT fatal.
#   external-network   needs a third-party service to be up. Runs in the
#                      `network-tests` job, reported, NOT fatal.
#
# There is deliberately no "skip" class. A test that nobody runs and nobody
# reports on is indistinguishable from a deleted test, and 21 files already
# reached that state once in this repository.
#
# tests/ci_nightly_registry_check.R fails the build when an entry names a file
# that no longer exists, so a stale exception cannot quietly outlive its cause.
# =============================================================================

# canonical-normalizer contract is verified locally, not nightly.
